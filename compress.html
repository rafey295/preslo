Frequently asked questions

Is my file really not uploaded anywhere?

Correct — everything happens inside your browser tab using WebAssembly. No server ever sees your file.

Why did my PDF's text become unselectable?

Compression rasterizes each page into an image to shrink file size. This trims size a lot but removes selectable text.

Is there a file size limit?

No hard limit — very large files just take longer to process since your device is doing the work.
